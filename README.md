# Hackaton-citiz

Projet réalisé pour le Hackathon Mobility (Epitech x Citiz x Microsoft).

**Objectif** : cartographier l'accès à la mobilité partagée en Occitanie et recommander où implanter de nouvelles stations Citiz, arrêts de bus ou stations de vélos, pour toucher le plus d'habitants au moindre coût.

## Territoire

Région Occitanie (13 départements).
