Données transport – Haute-Garonne (31)

Page de départ (tout Occitanie) : https://transport.data.gouv.fr/datasets/region/76

Transport public (GTFS)
Tisséo : bus, métro, tram de Toulouse et agglo. Réseau principal. → page régionale ci-dessus
liO Occitanie : bus interurbains, à filtrer sur le 31. → page régionale ci-dessus

Autopartage (GBFS)
Citiz Occitanie : stations existantes (garder le 31). https://transport.data.gouv.fr/datasets?type=vehicles-sharing&q=citiz
Getaround : voitures de particuliers, sans stations fixes. https://transport.data.gouv.fr/datasets?type=vehicles-sharing&q=getaround
Stations autopartage Toulouse Métropole : places réservées (candidats d'implantation). https://www.data.gouv.fr/en/datasets/stations-d-auto-partage-tm/

Vélos / trottinettes (GBFS)
VélôToulouse : stations de vélos. → page régionale
YEGO : scooters en free-floating. → page régionale
Catalogue GBFS (autres opérateurs) : https://github.com/MobilityData/gbfs/blob/master/systems.csv

Covoiturage (optionnel)
Lieux de covoiturage Haute-Garonne : points d'ancrage intermodaux. → page régionale

Base de calcul
OSM Midi-Pyrénées : réseau piéton pour les isochrones. https://download.geofabrik.de/europe/france.html
ADMIN EXPRESS : limites communales. https://geoservices.ign.fr/adminexpress

Formats
